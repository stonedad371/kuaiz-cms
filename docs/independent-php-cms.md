# 快智独立 PHP CMS 开发边界

## 目标

快智 CMS Community 是可独立安装、独立编辑、独立发布的开源 PHP CMS。用户不注册
快智账号、不购买域名授权，也能长期使用人工 CMS。快智中央总台是可选的 AI 自动运营
服务，不是网站公开访问或人工编辑的前置条件。

产品分为四个稳定层次：

1. **CMS Core**：身份、权限、内容、媒体、发布、回滚、备份、审计与升级。
2. **Theme SDK**：只负责 HTML、CSS、静态资源和声明式页面布局，不执行 PHP。
3. **Extension SDK**：承载目录、预约、会员和外部连接器等业务能力。
4. **AI Operations Connector**：由客户明确启用，向中央总台出站同步设置并领取签名任务。

快智引擎继续独立维护网页 FAQ AI 客服、企业微信自动客服和 AI 静态建站。快智 CMS 不进入
快智引擎的客户安装包，也不读取其账号、数据库或部署配置。未来需要 AI 建站时，只通过
CMS 明确启用、可撤销的接口或扩展连接。

## 不可破坏的边界

- 社区版 CMS Core 不需要域名许可证，授权到期不能关闭公开网站或人工编辑。
- 普通 Theme 不能运行 PHP、查询数据库、发起网络请求或写入服务器文件。
- Extension 不能修改 CMS Core 表；业务数据使用扩展自己的命名空间和迁移记录。
- 第一阶段不允许客户在后台上传任意 PHP。可执行扩展只接受官方审核和签名版本。
- 支付、资金、库存、物流和高并发实时业务优先连接外部成熟系统。
- AI 模型密钥、供应商私钥和中央运营策略不进入 CMS 交付包。
- 总台失联时，公开网站、人工编辑、备份和本地发布必须继续工作。

## Extension v1 信任级别

### 声明式内容扩展

只声明内容类型、字段、公开路由、权限和 Theme 插槽，不携带可执行 PHP。适合门店、
团队、课程、房源、案例目录等业务。它是第一阶段唯一允许自动安装的扩展类型。

### 官方签名 PHP 扩展

适合预约、会员和经过审核的外部连接器。必须声明最小权限、个人数据类别、保留期、
网络目标、数据库迁移和兼容版本。实现代码进入生产前必须通过签名、安全测试和人工确认。

### 第三方扩展

协议稳定前只允许提交和审核，不允许普通管理员直接上传运行。是否开放市场，要等至少三个
正式业务扩展完成跨版本升级、卸载保留数据和备份恢复演练后再决定。

## Theme SDK v2

Theme v2 是“声明式页面组件树”，不是固定成品模板，也不是 PHP 模板。设计师或用户自己的
AI 工具可以重新安排首页、列表页、详情页和 404 页的组件，设置品牌颜色、字体层级、留白、
圆角、页头与页尾，并把组件属性绑定到站点或内容字段。最终 HTML、结构化数据和安全转义仍
由 Core 渲染，因此主题不能绕过 SEO、可访问性和权限规则。

- 一个网站只选择一种内容语言；需要中文站和英文站时创建两个网站，不在 Theme 内实现多语言内容系统。
- Theme 可以同时声明 LTR 与 RTL 排版能力，以覆盖英语、中文、阿拉伯语等不同市场。
- Theme 不允许携带 HTML、JavaScript、PHP 入口或任意网络请求；首版只接受受控组件和标量选项。
- Theme 资产首版只允许 AVIF、WebP、PNG 和 JPG；不开放 SVG、自定义字体或自定义 CSS。
- 内容绑定只能读取 `site.*`、`page.*`、`content.*` 和 `collection.*` 语义字段，不能写 SQL 或直接读 Core 表。
- 扩展通过注册的 `extension_slot` 接入页面，Theme 不能调用未安装扩展的内部实现。
- 发布前必须跑移动端和桌面端，并覆盖短数据、长数据、复杂状态、空数据与 RTL 五类种子。
- 颜色组合必须达到正文 4.5:1 对比度；标题层级、canonical、结构化数据和站点地图由 Core 控制。

## 数据与权限

- Core 表统一使用 `cms_` 前缀。
- 扩展标识使用反向命名空间，例如 `kuaiz.appointment`。
- 扩展自有表使用经过 Core 分配的前缀，禁止使用或仿冒 `cms_`。
- 每个扩展版本的 manifest 内容不可变；同版本不同哈希拒绝安装。
- 版本降级默认拒绝；恢复旧版本必须走备份恢复，不执行逆向迁移猜测。
- 扩展权限、路由、事件、Theme 插槽和个人数据声明都进入本地审计。
- 卸载默认停用而不删除业务数据；数据删除必须是单独、可审计的管理员动作。

### 本地后台身份

- 本地 CMS 使用独立账号，不依赖快智总台在线；用户名可以是普通用户名或邮箱。
- 密码只保存 PHP `password_hash` 结果；会话令牌和防伪令牌只保存 SHA-256 摘要。
- 连续登录失败按账号和客户端双向限流，后台只返回统一的登录失败提示，避免枚举账号。
- 会话固定 12 小时，到期不自动续期；修改密码、停用账号或改变角色会撤销相关会话。
- `admin` 管理账号与全部内容，`editor` 编辑和发布内容，`viewer` 只读；最后一个有效管理员不能被停用或降权。
- 登录、退出、账号创建、权限变化和密码变化都写入本地审计日志，不记录密码或原始令牌。
- 首个管理员不能靠“抢先打开网站”创建；安装命令生成 256 位一次性启用码，数据库只保存摘要，使用后立即删除。

### 内容后台服务

- 内容列表按扩展、类型和状态筛选，明确区分当前草稿与线上已发布版本。
- 每次保存都创建不可变修订；修改草稿不会让线上内容提前变化。
- 发布、下线、归档和恢复归档只改变入口状态，不删除历史修订。
- 公开读取只接受启用扩展的已发布修订，并在返回前校验内容哈希。
- 管理界面只能调用 Core 服务完成上述动作，不能直接拼接 SQL 修改内容状态。
- 管理后台首版采用服务端渲染且不运行 JavaScript，强制安全 Cookie、CSP、同源表单和写操作防伪校验。

### 媒体安全

- 首版只接收 JPG、PNG 和 WebP，最大 12MB、1200 万像素；不接收 SVG、视频或其他可执行格式。
- 上传图片必须经过 Fileinfo 与图片解码双重识别，再由 GD 重新编码为 WebP，不直接保存用户上传的原文件。
- 自动生成 640px 缩略图，主图最长边限制为 3000px；原始文件名只作为后台说明，不参与存储路径。
- 图片文件使用内容哈希分目录保存于 Web 根目录之外，后台预览必须先通过 CMS 登录权限。
- 每个内容修订记录图片引用；被当前草稿或线上版本使用的图片不能归档，历史修订仍保留文件。

### 公开站点与 SEO

- 网站设置只保存一个内容语言和一个排版方向；需要第二种语言时建立第二个网站。
- 新站默认关闭搜索收录，同时输出页面级 `noindex` 和全站 `robots.txt` 禁抓取；管理员确认
  正式 HTTPS 域名与内容后才显式开启。
- Core 只把启用扩展的已发布修订交给 Theme，草稿、已下线和已归档内容不进入首页、列表、
  详情页或 Sitemap。
- Core 统一输出自引用 Canonical、语言、Open Graph、JSON-LD、CSP、404 `noindex` 和 Sitemap；
  Theme 不能覆盖这些安全与 SEO 决策。
- 公开图片 URL 带内容哈希并使用不可变缓存；文件哈希、数据库记录或存储边界不一致时返回 404。

### 备份、恢复与迁移回滚

- 备份使用普通目录和 JSON 清单，不依赖 Zip 扩展；只复制 SQLite 和数据库登记过的媒体、
  Theme 资产，不执行或恢复任意 PHP。
- 清单锁定 runtime profile、schema 版本、相对路径、文件大小和 SHA-256；恢复先验完整清单，
  再在隔离目录迁移并检查数据库与文件引用。
- 恢复会先自动创建当前网站的 `pre-restore` 安全备份，再原子切换数据库、媒体和 Theme；
  任一步失败都优先回滚，回滚不完整时保留现场目录而不继续清理。
- Web 请求持有共享维护锁，备份和恢复持有独占锁；维护期间新请求快速返回暂时不可用，
  不会在文件切换中间读取网站。
- 每次 schema 升级前创建独立 SQLite 快照。迁移或完整性检查失败时自动恢复旧库，并保留
  失败数据库；成功后只保留最近 5 份迁移前快照。

### 单文件安装

- 发布构建器把严格白名单内的 CMS 源码、协议、参考扩展和参考 Theme 内嵌到一个专属 PHP；
  客户主机不需要 Zip，也不在网页表单中提交下载地址或服务器命令。
- 每个版本先生成只含模板哈希、载荷哈希、版本、文件数、总字节数和发行时间的规范摘要，
  再由隔离的 CMS 专用 Ed25519 私钥签名。签名机不接触源码，下载服务不持有私钥。
- 安装器在展示管理员密码表单前验证发行签名、原始模板、内嵌载荷和公钥指纹；任何普通
  字符篡改都会失败关闭。可信公钥指纹必须由 `cms.kuaiz.net` 和下载服务的固定配置独立
  提供，不能把安装文件自带的公钥当作唯一信任来源。
- 每份安装文件带一个只保存摘要的专属安装码。安装表单收网站名称、唯一语言、详细业务介绍、
  管理员邮箱、称呼和至少 12 位密码，也可以自动生成 16 位密码。HTTP 主机可以安装，但页面
  会提醒传输风险；正式网址从当前访问域名取得，密码直接进入本地 `password_hash`，不写安装
  记录或总台。新站默认禁止搜索引擎收录。
- 安装器逐文件核对大小和 SHA-256，在网站根目录上一级的隔离目录完成 SQLite 初始化、参考
  扩展注册、Theme 激活和管理员创建，再提交三个公开入口文件。
- 发现现有 `index.php`、`.htaccess` 或 `.user.ini` 时失败关闭；不会为了“自动”而覆盖旧站。
  私有内核已完成但公开入口中断时，可以用同一专属安装器续接，但必须先重验全部内核哈希。
- 安装成功后自动删除上传的安装文件。首版自动 URL 改写支持 Apache/LiteSpeed；不支持的主机
  在落盘前停止，后续使用服务器专用档案，不把 SQLite 或源码放回公开目录。
- CI 分别在真实 Apache PHP 与 OpenLiteSpeed `lsphp83` 容器中经 HTTP 完成整套安装，并验证
  后台重写、robots、404、点文件保护、数据库与签名回执。OpenLiteSpeed 官方行为是新建
  `.htaccess` 后需刷新服务器，矩阵会明确验证刷新前后状态；首版不能宣称它零操作安装。

## 开发阶段

### 阶段 A：独立内核基础

- 社区版分发清单。
- SQLite 内容、修订、发布、扩展和审计基础表。
- Extension manifest 严格校验器。
- 声明式内容扩展注册器。
- 一个不含可执行代码的目录型参考扩展。
- 本地账号、三类角色、登录限流、安全会话和审计。
- 内容后台列表、版本历史、发布、下线、归档与恢复服务。

### 阶段 B：可用 CMS

- PHP 管理后台的页面、文章、媒体、栏目、SEO、发布和历史恢复。
- Theme SDK v2、示例数据、预览和自动验收命令。
- 独立安装器、备份、恢复和连续数据库迁移。
- Community CMS 全新安装以及同产品线内的升级、备份与恢复。

### 阶段 C：业务扩展

- 先实现官方预约扩展，验证权限、通知、定时任务、隐私和 Theme 插槽。
- 再实现官方会员扩展，补齐身份、找回密码、数据导出和删除。
- CRM、日历和支付使用外部连接器，避免 CMS 承担不必要的高风险能力。

### 阶段 D：对外发布

- `cms.kuaiz.net` 产品主页、文档、下载和安全公告。
- 上传即安装的 PHP 包和 Docker 开发环境。
- AI 工具可读取的 JSON Schema、示例数据和本地验证命令。
- 可选连接快智 AI 自动运营，按正式域名购买年度服务。

## 与快智引擎的接入规则

本仓库是快智 CMS 的唯一代码源。快智引擎不能复制本仓库源码、直接读取 CMS 数据库，或把
CMS 塞进原有静态站安装包。未来任何连接都必须使用版本化接口或签名扩展，并同时完成：

1. Community CMS 连续版本升级与恢复测试；
2. 安装前备份与失败恢复测试；
3. PHP 真实运行测试；
4. 任意扩展不能执行的安全测试；
5. 现有安装器、任务验签和静态发布全量回归。

当前开发测试版已完成本地身份、角色、登录限流、安全会话、内容修订与状态管理、服务端管理后台、
安全媒体库、Extension v1 声明式协议、Theme v2 合同与版本化安装、Core 控制的公开页面与
SEO 输出、带哈希清单的备份恢复和 schema 迁移失败回滚，以及内嵌白名单源码的专属单文件
安装器，以及模板与内嵌源码一体校验的离线签名发布流程。尚未完成的交付门槛包括
`extension_slot` 的公开业务渲染、生产发行密钥托管与官网指纹发布、Apache/OpenLiteSpeed
CI 矩阵持续运行、独立 CMS 浏览器可视化基准，以及 Community CMS 连续版本升级和回滚演练。
当前版本已经可以公开测试，但仍不建议承载重要业务，也不会替换快智引擎现有的静态建站交付。
