# 快智 CMS 稳定支持版范围与门禁

本文定义 Community CMS 从 Developer Preview 进入 Release Candidate，再进入 Supported
稳定支持版的产品边界。版本名称不能只根据功能数量决定；所有必选门禁都必须有可复核证据。

## 首个稳定支持版承诺

首个稳定支持版面向单站、单语言的企业展示与内容目录网站。用户在不连接快智总台的情况下，
必须能够完成：

- 用一个 `install.php` 在已验证的 Apache 或 OpenLiteSpeed PHP 主机安装与升级；
- 使用本地管理员、编辑和只读成员账号，并自行修改密码和管理成员权限；
- 创建、搜索、分页、修订、发布、下线、归档和恢复结构化内容；
- 上传、搜索、分页和归档本地图片，并生成适合公开访问的安全图片；
- 切换内置主题，使用 LTR 或 RTL 单语言页面，并在手机与桌面正常显示；
- 输出 Canonical、结构化数据、`robots.txt` 和包含全部已发布内容的站点地图；
- 从后台创建本地备份，由主机管理员通过命令行校验、恢复并保留恢复前安全备份；
- 从上一受支持版本原地升级，失败时保留原内核、数据库和用户文件；
- 在快智服务离线或从未连接时继续公开访问、人工编辑、发布和备份。

以下能力不属于首个稳定支持版承诺：预约、会员、支付、电商、邮件投递、多站点、单站多语言、
管理员上传第三方 PHP、Nginx/IIS 一键安装，以及快智 AI 自动运营。以后只能作为独立版本化
能力加入，不能破坏上述离线闭环。

## 状态定义

- **Developer Preview**：核心路径可用并有自动测试，但接口、升级范围和支持承诺仍可能调整。
- **Release Candidate**：产品范围冻结，使用生产离线信任根签名；所有自动门禁通过，只接受
  阻断发布的问题与文档修正。
- **Supported**：候选版完成真实站点观察、恢复演练与公网复核，官网明确公布支持期限和安全
  联系方式。

## 自动门禁

每次候选和稳定发行都必须在同一提交上通过：

1. PHP 7.4、8.1、8.2、8.3、8.4、8.5 语法、功能与 schema 升级测试；
2. Apache 7.4 无重写、受限父目录、无 WebP、标准 Apache 和 OpenLiteSpeed 六种真实安装；
3. 上一公开版到当前版的真实 HTTP 升级，以及公开文件冲突后的完整回滚；
4. Chromium 桌面和手机上的短内容、长内容、复杂字符、空数据、RTL 与后台关键页；
5. 源码白名单、可复现 ZIP、安装载荷、签名摘要、官网链接和站点地图检查；
6. 备份创建、完整性校验、恢复前安全备份和数据库升级失败保护。

## 人工与外部门禁

下列项目不能由仓库测试替代，进入 Supported 前必须附上日期、执行人和证据地址：

- 使用离线生产发行根完成双人复核签名；Developer Preview 的联网本机钥匙串不能提升状态；
- 为 `main` 开启禁止强推、必须 Pull Request、必须通过全部 CI、至少一位代码所有者批准；
- 候选版在至少两个相互独立的真实主机账户连续运行 14 天，其中至少一个 PHP 8.2+；
- 在真实站点副本完成一次升级、备份、破坏性恢复演练和应用回退，核对账号、内容、图片与 SEO；
- 从官网重新下载安装器，独立核对版本记录、SHA-256、公钥指纹并做一次空站安装；
- 公布支持期限、安全报告渠道、已知限制、升级说明和紧急暂停下载/回滚负责人；
- 普通用户按公开文档完成一次无人指导的安装、建管理员、发布内容和创建备份走查。
