01 · 产品说明

自己的网站，可以独立使用

账号、内容、图片、发布记录和备份都放在你自己的主机上。AI 运营是可选服务，不开通也不影响网站访问和人工更新。

  • 公开网站、后台编辑和备份不依赖快智一直在线
  • 一个网站使用一种主要语言，服务不同市场时分别建站
  • 页面样式只能改变展示，不能读取密码或改动重要数据
  • 源码已经公开，可以按照开源许可证自行使用和修改
当前是开发测试版适合了解产品、搭建测试站和参与改进；需要长期稳定运行的重要项目，请等待稳定版或先联系我们评估。
02 · 安装前准备

准备一个空网站和能打开的域名

安装文件会自己检查主机。你只需要能在主机面板上传文件，并知道这个域名对应的网站根目录。

  • 域名已经能正常打开，HTTP 和 HTTPS 都可以
  • 网站根目录里没有需要保留的旧首页
  • 主机使用 PHP 7.4 或更高版本
  • 主机允许程序在网站根目录写入文件
上一级目录不可写也能装安装器会优先把数据库放在网站根目录外；主机不允许时，会自动改用根目录内只供程序使用的独立位置。
没有 HTTPS 也能装安装页会显示密码传输提醒，但不会拦住。请避免在公共 Wi-Fi 下安装，有条件时再开启 HTTPS。
没有 WebP 也能装主机只要开启常见的 GD 图片功能即可；不支持 WebP 时，系统会自动使用 JPG 或 PNG。
主机面板怎么选如果有 PHP 8.2 或更高版本，优先选新版本；如果最高只有 PHP 7.4，也可以安装。PHP 5.x 到 7.3 不支持。
不确定也可以先上传打开 install.php 后，它会自动检查主机；不满足要求时只显示原因，不会开始安装。
03 · 三步安装

下载、上传、打开

下载 install.php

从快智 CMS 官网下载。文件名应当是 install.php，不需要解压。

上传到网站根目录

在主机面板的文件管理器中，把它放到这个域名存放首页文件的目录。

打开安装页面

浏览器访问 你的域名/install.php。主机有 HTTPS 就使用 HTTPS，没有也可以直接用 HTTP 打开。

上传后请马上打开安装页面用于空网站。发现已有首页或关键设置文件时，它会停止并保护原文件，不会强行覆盖。
04 · 填写安装页面

一次填写，安装完成直接进后台

填写网站信息

填写网站名称、主要语言和业务介绍。业务介绍建议 50–200 字，最多 500 字，输入框下方会显示已经填写的字数。

创建管理员

填写管理员邮箱和称呼。密码可以自己填写，至少 12 位；也可以点“自动生成 16 位”，页面会自动填好两次。记得点“复制密码”并保存到安全的地方。

点击安装

程序会建立网站、放好数据并创建管理员，不需要安装码或命令行。

打开网站后台

完成后点击“打开网站后台”，以后固定访问 你的域名/admin/。

添加并预览内容

先创建几篇测试内容，检查首页、列表页、详情页和手机显示。

准备好后再允许搜索收录

新网站默认不让搜索引擎收录。内容和联系方式检查完，再到网站设置里开启。

安装文件会自动清理安装成功后，install.php 会尝试自动删除。如果页面提醒无法删除，请回到主机文件管理器手动删除。
页面打不开

看到 Not Found，重新上传安装文件修复

这通常是主机没有开启网址转发，不代表网站内容丢了。使用最新版安装文件，就能一起补好公开内容页和后台入口。

重新下载 install.php

从官网下载最新版，不需要重新下载网站压缩包。

上传到原来的网站根目录

和现有 index.php 放在同一目录，不要删除数据库、图片或其他文件。

再次访问“你的域名/install.php”

页面找到现有网站后，点击“修复并打开网站后台”。

重新打开原来的地址

原有内容页和后台都能继续打开，管理员、设置、内容和图片也会保留。

修复不是重装安装文件只更新程序和页面入口，不会清空现有网站数据；完成后也会自动删除自己。

07 · 备份恢复

重要操作前，先留一份完整备份

平时发布内容不需要命令行。下面的命令给主机维护人员使用，分别用于检查网站、建立备份和恢复备份。

php bin/cms-doctor.php php bin/cms-backup.php php bin/cms-restore.php /absolute/path/to/backup-directory --yes
  • 检查网站环境、数据目录和数据库是否正常
  • 备份会包含内容、图片和完整文件清单
  • 升级失败时尽量恢复到升级前的状态
  • 恢复旧备份前，系统会先保存当前网站
把数据和程序分开放数据库、图片和备份不要放在公开网页目录里。升级程序时，也不要跟着搬动客户数据。
08 · 主机要求

哪些主机更容易安装

主机环境当前情况说明
Apache + PHP 8.2+推荐适合新网站和正式运营，仍需满足上面的 PHP 功能和根目录权限。
Apache + PHP 7.4已经测试包括根目录上一级不可写的共享主机；正式运营时仍建议联系主机商升级。
OpenLiteSpeed / LiteSpeed已经测试安装后可能需要在主机面板刷新网址转发设置。
PHP 5.x – 7.3不支持请在主机面板选择 PHP 7.4 或更高版本。
Nginx需要技术人员配置不能直接照搬 Apache 设置，正式安装前请先确认。
IIS暂未支持当前版本不建议使用。
09 · 核对下载

只从官网进入下载

官网下载页会显示版本用途，并提供文件校验资料。普通用户只要确认来自 cms.kuaiz.net，并看清“开发测试版”或“稳定支持版”即可。

  • 开发测试版适合体验，不建议承载重要业务
  • 稳定支持版才会进入长期维护和安全更新范围
  • 安装或升级前，无论什么版本都要先备份
